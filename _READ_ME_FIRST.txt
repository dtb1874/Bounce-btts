BOUNCE BTTS — TYNECASTLE TABLE WATERMARK UPDATE

This update adds a very faint, original Tynecastle Park facade line-art watermark to:
- the dashboard mini league table
- the full members' league table
- the public read-only league table
- the JPEG table snapshot shared to WhatsApp

UPLOAD STEPS
1. Unzip this package.
2. Open the dtb1874/Bounce-btts GitHub repository.
3. Choose Add file > Upload files.
4. Upload the app and public folders from this package into the TOP LEVEL of the repository.
5. Allow GitHub to replace app/layout.tsx and app/ShareTableButton.tsx.
6. Confirm these new files are included:
   app/tynecastle-watermark.css
   public/assets/tynecastle-facade.svg
7. Commit with the message: Add Tynecastle table watermark

Do not upload this instruction text file to the app; it is only a guide.
