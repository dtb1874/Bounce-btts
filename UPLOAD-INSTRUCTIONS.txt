BOUNCE BTTS — DASHBOARD / LEAGUE TABLE RESTORE — 10 AUGUST 2026

This package corrects the remaining UI regression from the combined release.

WHAT IS RESTORED / ADDED
- Dashboard is again a full overview rather than a condensed utility screen.
- Desktop: large league overview, role-aware summary cards, current pick, everyone’s picks/live results,
  rich league-table preview, trophy/crest imagery, quick links, and 6-week form.
- Mobile: same information is retained but stacked into clean cards rather than shrinking the desktop layout.
- Admins see an admin-focused overview including outstanding alert count and Admin shortcut.
- Members see their own position, points, pick, current gameweek and the same league overview.
- League Table page has its richer presentation back, including the Bounce cup artwork and leader treatment.
- 6-WEEK FORM is restored to the Dashboard. It shows the selected/current gameweek and up to the previous 5 weeks.
  +3 = BTTS win, +1 = score-nil, -1 = 0-0/missed, — = not yet scored.
- Existing scoring fix, About page, alerts/admin controls and sidebar Rousset easter egg remain.

IMPORTANT
This package uses only assets already known to exist in the project:
- /assets/hearts-crest.png
- /assets/bounce-cup.png

UPLOAD
1. Extract the ZIP.
2. In GitHub Bounce-btts choose Add file -> Upload files.
3. Upload the APP folder to the repository ROOT.
4. Replace:
   app/LeagueApp.tsx
   app/release.module.css
5. Commit.
6. Vercel deploys automatically.

Do NOT remove lib/scoring.ts.
No Supabase or Vercel configuration changes are needed.
