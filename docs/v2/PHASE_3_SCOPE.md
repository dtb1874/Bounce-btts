# V2 Phase 3 — Scope

This phase is a deliberate visual reset of the first V2 preview. It does not alter production and does not change canonical league rules.

In scope:

- a new editorial Dashboard presentation;
- a fully restructured Stat Centre preview;
- a premium Admin control-centre preview;
- preview chrome aligned with the new visual language;
- documentation that locks the less-blocky premium design direction.

Out of scope for this phase:

- replacing the remaining V2 surfaces;
- changing scoring, fixture eligibility, schedule propagation or historical rules;
- merging anything into `main`;
- declaring V2 release-ready.

The branch remains a design/development preview until the new direction is approved and then becomes the visual baseline for the remaining V2 product areas.
